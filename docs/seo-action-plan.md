# builtwithai.ca — SEO Action Plan

**Goal:** rank for **"Built with AI Canada"**, **"AI consulting Canada/Regina/Saskatchewan"**,
and branded searches. (The bare term "built with ai" is owned by large unrelated
communities and is not a realistic target — ignore it.)

**Key fact to set expectations:** Google shows a site only after it *crawls* it. A brand-new
page takes **days to ~3 weeks** to appear after publishing. Nothing speeds this past the steps
below — this waiting period is normal and unavoidable.
